# Artifact Scope

## Purpose

This artifact package supports evidence auditing for ContextPerf.

## Included purpose

The package is intended to help reviewers inspect:

- evidence provenance;
- compact result records;
- figure/table generation inputs where permitted;
- hash manifests.

## Excluded

The package does not include:

- private experiment infrastructure;
- credentials;
- cluster access information;
- unavailable third-party datasets;
- a claim of full historical experiment reproduction.

The artifact scope follows the manuscript claim boundary.
