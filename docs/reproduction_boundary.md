# Reproduction boundary

## Supported checks

1. Verify SHA-256 identities of every delivered file and reject unlisted files.
2. Inspect the complete frozen Figure 3 and its preserved points and uncertainty intervals.
3. Inspect retained paired compact records, logical-digest/shape witnesses, timing-disabled work laws, and negative direct-template-equivalence findings.
4. Compare opaque provenance records with author-controlled original bytes when those are separately available under appropriate permission.

## Not provided

The package cannot rerun historical database experiments or recover missing raw bytes. There are no complete runtime environments, launchers, database builds, original native databases, complete logs, all per-invocation readbacks, or full experiment roots. Native execution, original sampling, estimator validity, bootstrap calculations, and independent backup completeness are not established by a successful checksum or compact-record consistency check.

E1's historical protocol describes a per-file cold allowance, while the actual fixture asserts summed residency against 64 KiB times file count. Its native open/preload assertions occur after the timed invocation. Those historical checks must not be presented as a completed generalized pre-outcome admission barrier. The figure and compact files do not include every admission receipt.

E2 combines two adjacent batches rather than one atomic nine-setting run. Its stored median-derived ratio must not be silently replaced with median(pair ratios). No intervals are regenerated here. Figure panels have different ratio directions and protocols and must not be pooled.

E3 and E4 counters are timing-disabled mechanism observations. E3's contaminated historical timing costs remain unusable for elapsed-performance, overhead, or reproduction-effort claims. E5 is analytical and uses existing data. No prospective receipt-controlled comparison or full end-to-end implementation evaluation is supplied.

## Integrity and transformation limits

Most selected source files and the frozen SVG are copied byte-for-byte. The E2 CSV removes private source paths using stable batch aliases, renames two misleading historical policy headers, and retains all numeric and Boolean cells verbatim. Source and derived hashes are separate. The selected source records are identified by commit and hash, not by public URLs. The original source archives remain excluded.

The manifest and checksum inventory are unkeyed integrity records, not cryptographic proof of trusted authorship. A party changing both content and checksums can create a self-consistent package. After approval, record an immutable release commit and a trusted release checksum through the chosen distribution channel.

No new experiment, reanalysis, confidence interval, or scientific result was produced while preparing this candidate. Package verification is only a local file and consistency check.
